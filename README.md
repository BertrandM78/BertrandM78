### [IBM × Probabl Hackathon — Parkinson's prediction](https://github.com/BertrandM78/ibm-probabl-hackathon)
*Machine Learning · Predictive Modeling · Experimentation*

**7th out of 295 teams.** Built a reproducible ML experimentation pipeline to estimate Parkinson's OFF motor scores from incomplete, noisy longitudinal data.

- **2.510 cross-validation RMSE**, compared with a **16.51 naive baseline**.
